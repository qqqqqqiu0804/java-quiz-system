# Java Quiz System v1.4.0 Design
# 学习统计面板功能设计

## 概述

为Java期末考试刷题系统添加学习统计面板，展示答题数据、学习时长、章节分析和学习趋势。

## 功能需求

### 1. 标签页扩展

在首页顶部添加第四个标签页：
- **学习统计**：展示学习数据和图表

### 2. 答题概况（数字卡片）

显示以下数据：
- **总答题数**：用户累计答过的题目数量
- **正确数**：答对的题目数量
- **错误数**：答错的题目数量
- **总正确率**：正确数 / 总答题数 × 100%

### 3. 学习时长（数字卡片）

显示以下数据：
- **累计学习时间**：从第一次使用至今的总学习时间
- **今日学习时间**：今天的学习时间

**时间追踪方式：**
- 每次进入答题/考试页面时开始计时
- 每次退出答题/考试页面时停止计时
- 将学习时长累加到localStorage

### 4. 章节分析（柱状图 + 数据）

**柱状图：**
- X轴：7个章节
- Y轴：正确率（0-100%）
- 每个章节一个柱子，颜色区分

**数据展示：**
- 每个章节的答题数、正确数、正确率
- 薄弱知识点提示：正确率最低的章节（低于60%标红）

### 5. 学习趋势（折线图）

**显示最近7天的数据：**
- 折线1：每日答题数量
- 折线2：每日正确率

**数据格式：**
```javascript
{
  "2026-06-01": { total: 20, correct: 15 },
  "2026-06-02": { total: 30, correct: 25 },
  ...
}
```

### 6. 数据管理

提供以下操作：
- **导出数据**：将所有统计数据导出为JSON文件下载
- **导入数据**：从JSON文件恢复统计数据
- **清除数据**：清除所有统计数据（需确认）

```javascript

  // 答题概况
  totalAnswered: 150,
  totalCorrect: 120,
  
  // 学习时长（秒）
  totalStudyTime: 3600,

  lastStudyDate: "2026-06-02",
  
  // 章节统计
  chapterStats: {
    "chapter1-2": { answered: 30, correct: 25 },
    "chapter3": { answered: 20, correct: 18 },
    "chapter4": { answered: 15, correct: 10 },
    "chapter5": { answered: 25, correct: 20 },
    "chapter6": { answered: 10, correct: 8 },
    "chapter7": { answered: 20, correct: 17 },
    "chapter9": { answered: 30, correct: 22 }

  // 每日趋势（最近30天）
  dailyStats: {
    "2026-06-01": { total: 20, correct: 15 },

    ...
  }

```

### localStorage 键值

- `java-quiz-stats`：统计数据
- `java-quiz-study-timer`：学习计时器状态

## 技术实现

### Chart.js 使用

通过CDN引入Chart.js：
```html
<script src="https://cdn.jsdelivr.net/npm/chart.js"></script>
```

### 新增功能模块

1. **StatsManager** - 管理统计数据的存储和计算
2. **StudyTimer** - 追踪学习时长
3. **Charts** - 渲染柱状图和折线图

### 数据收集时机

- 每次答题完成时（submitQuiz/submitExam）更新章节统计和每日统计
- 每次进入答题页面时开始计时
- 每次退出答题页面时保存学习时长

### 导出/导入格式

```json
{
  "version": "1.4.0",
  "exportDate": "2026-06-02T10:30:00",
  "stats": {
    // 统计数据
  }
}
```
