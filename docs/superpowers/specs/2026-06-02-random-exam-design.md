# Java Quiz System v1.3.0 Design
# 随机刷题 + 模拟考试功能设计

## 概述

为Java期末考试刷题系统添加随机刷题和模拟考试功能，采用标签页切换的方式组织界面。

## 功能需求

### 1. 标签页切换

在首页顶部添加三个标签页：
- **章节练习**：现有功能，保持不变
- **随机刷题**：新功能
- **模拟考试**：新功能

### 2. 随机刷题模式

#### 范围选择
- **全部章节**：从所有169道题中随机抽取
- **选章节随机**：勾选多个章节，从选中的章节中随机抽取

#### 题量设置
提供常用选项：
- 10题
- 20题
- 50题
- 100题
- 自定义输入框（1-169）

#### 答题流程
1. 选择范围和题量
2. 点击"开始刷题"
3. 随机抽取题目，进入答题模式
4. 答题界面与现有章节练习相同（即时反馈）
5. 答完显示成绩和错题

### 3. 模拟考试模式

#### 题量设置
提供常用选项：
- 20题
- 30题
- 50题
- 100题
- 自定义输入框（1-169）

#### 时间设置
提供常用选项：
- 30分钟
- 60分钟
- 90分钟
- 120分钟
- 自定义输入框（1-180分钟）

#### 答题流程
1. 选择题量和时间
2. 点击"开始考试"
3. 随机抽取题目，进入考试模式
4. 考试模式特点：
   - 不显示即时反馈
   - 显示可拖动浮窗计时器
   - 可以跳题、返回上一题
5. 提交方式：
   - 手动提交
   - 时间到弹出提醒
   - 30秒后自动提交

#### 计时器浮窗
- 位置：右上角，默认位置
- 可拖动：鼠标按住可拖动
- 显示内容：剩余时间（分:秒）
- 样式：半透明背景，醒目但不遮挡题目
- 最小化：可点击最小化，只显示图标

## 技术实现

### 数据结构

#### 标签页状态
```javascript
{
  activeTab: 'chapter' | 'random' | 'exam'
}
```

#### 随机刷题配置
```javascript
{
  mode: 'all' | 'selected',
  selectedChapters: ['chapter1-2', 'chapter3', ...],
  questionCount: 10
}
```

#### 模拟考试配置
```javascript
{
  questionCount: 50,
  timeLimit: 90  // 分钟
}
```

#### 考试状态
```javascript
{
  questions: [...],
  answers: {},
  startTime: Date.now(),
  timeRemaining: 5400,  // 秒
  isSubmitted: false
}
```

### 新增功能模块

1. **TabManager** - 管理标签页切换
2. **RandomQuiz** - 随机刷题逻辑
3. **ExamMode** - 模拟考试逻辑
4. **Timer** - 可拖动计时器组件

### localStorage 新增键值

- `java-quiz-random-config` - 随机刷题配置
- `java-quiz-exam-config` - 模拟考试配置
